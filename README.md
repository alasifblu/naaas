# NAAAS Holding Venture BD Ltd.

Next.js 15, Tailwind CSS, and shadcn/ui landing experience for NAAAS Holding Venture BD Ltd.

## Highlights

- App Router with localized `/en` and `/bn` routes
- Reusable section and shadcn-style UI components
- SEO metadata, Open Graph, sitemap, and robots routes
- Responsive layouts and scroll-triggered animations
- Contact inquiry form with a Vercel-ready API route
- Remote image configuration for optimized Unsplash assets

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000/en`.

## Deploy on Vercel

Import this folder in Vercel, set `NEXT_PUBLIC_SITE_URL`, and deploy. The default build command is `npm run build`.
